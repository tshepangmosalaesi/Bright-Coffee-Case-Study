# Bright Coffee Shop Sales Analysis

## Project Overview

This project analyses sales data from Bright Coffee Shop to identify sales trends, product performance, peak sales periods, and customer purchasing behaviour. The analysis was completed using SQL, Databricks, Excel, and various data visualisation tools to provide business insights and recommendations.

## Project Objectives

* Analyse sales performance
* Identify best-selling products
* Analyse sales by time intervals
* Evaluate customer purchasing behaviour
* Provide business recommendations
* Present findings through dashboards and a presentation

## Project Workflow

1. Review the project requirements.
2. Plan the project architecture and timeline.
3. Import and clean the dataset.
4. Process and transform the data using Databricks SQL.
5. Perform data analysis.
6. Develop interactive dashboards.
7. Present findings and business recommendations.

## Key Insights

* Best-selling products
* Revenue by product category
* Peak sales periods
* Customer purchasing patterns
* Sales trends over time

## Business Recommendations

* Increase stock for high-performing products.
* Promote low-performing products through special offers.
* Introduce promotions during off-peak hours.
* Optimise staffing during peak periods.
* Implement customer loyalty programmes.
